# AI Short-Form Video Generator

An automated pipeline for generating short-form videos from Reddit content.

The project scrapes Reddit posts, processes the text, and turns the content into ready-to-publish short-form videos with minimal manual work.

## Features

- Reddit content scraping
- Automated text processing
- Video generation pipeline
- Repeatable workflow for producing multiple videos efficiently

## Tech

- Python
- Web scraping
- Automation
